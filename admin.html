Backup & Preservação dos Dados

Todas as alterações feitas no catálogo e textos são salvas automaticamente no armazenamento local do navegador. Para garantir sua segurança ou transferir os dados para outro computador, utilize as ferramentas de backup abaixo:

Baixar Cópia de Segurança Gera um arquivo .json com todos os produtos, fotos e configurações.
Restaurar Cópia de Segurança Carregue um arquivo .json previamente exportado.
Restaurar Dados de Fábrica Recarrega o acervo inaugural de produtos e textos originais.
